# Medical Dosimetry Graduate E-Portfolio

A polished, responsive starter website for a medical dosimetry student with a radiation therapy background.

## Files
- `index.html` — complete portfolio content and structure
- `styles.css` — responsive academic/clinical visual design
- `script.js` — mobile navigation behavior

## Customize first
1. Replace placeholder education/program information.
2. Add a professional photo if desired.
3. Replace the résumé placeholder with your PDF link.
4. Add professional email and LinkedIn.
5. Add your second publication and links/DOIs.
6. Add only fully de-identified clinical images and case information.
7. Add screenshots of treatment plans, DVHs, or coursework projects where permitted.
8. Replace generic case-study cards with your actual projects.

## Publishing
The files can be uploaded to GitHub Pages, Netlify, Vercel, or another static hosting service. No server/database is required.

## Privacy
Never publish patient identifiers, dates of birth, medical record numbers, accession numbers, screenshots containing names, or other protected health information. Follow your clinical site's policies before publishing any clinical material.
